    Shared design principles

    • Agents interpret and adapt. Code controls the rules. Every AI action is bounded by fixed permissions, answer checks, retry limits, and human approval gates.
    • Human-in-the-loop. Concept 01 prepares a clarification request for the educator to review/send. Concept 02 pauses hints and notifies an authorized adult when independent checks fail.
    • Controlled information access. Agents retrieve only approved evidence and cite sources (dates, systems) so families can verify what's current.
    • Participation by design. Parents, students, teachers, and advisers remain involved - AI supports the relationship, it does not replace it.
    • Workflow (LangGraph-style): User action → fixed permission/answer check → AI reviews → controlled access → check/adjust/ask a person.
    • Safety: Fictional demo data only; MCP tools give agents limited data access; prototype receives the required ArgosX security scan.
