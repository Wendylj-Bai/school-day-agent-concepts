Two proposals for team consideration

Recurring education needs, designed as bounded agent workflows.

One concept gives families a clearer connection to school information and educator follow-up. The other helps a learner move forward after a mistake while keeping parents and educators involved. Technology supports the relationship; it does not replace it.

Decision boundary: These are working hypotheses, not validated school needs, implemented products, or claims of measured impact. The purpose of this site is to help the team compare them before choosing what deserves deeper research and construction.
Compare the directions

Two users. Two recurring jobs. Two different agent loops.

The concepts are alternatives, not parts of one oversized school platform.

01
Family communication

Family-School Communication Coordinator

For: Parents, students, teachers, and advisers coordinating school information and follow-up.

Value: One authorized place for important notes, assignments, projects, events, results, questions, and educator follow-up.

  • Evidence Agent retrieves approved information within the family’s permitted scope.
  • Coordination Agent provides a sourced answer or prepares an educator follow-up.
  • The application independently enforces identity, privacy, and record-level access.

02
Adaptive learning support

Personalized Study Buddy

For: A learner practicing a skill, with parents, teachers, or advisers supporting progress.

Value: A better explanation and a fresh check question, plus an appropriate support signal when human follow-up would help.

  • Learning-State Agent identifies a possible misconception from attempts.
  • Teaching Agent selects a vetted activity and guides the next step.
  • A deterministic checker assesses the response; authorized adults receive only useful progress and support information.

Shared design principle

Agents interpret and adapt. Code controls the rules.

The proposed designs use multiple agents only where responsibilities are meaningfully different.

LangGraph

Suggested orchestration layer for explicit state, agent routing, tool calls, retry limits, and human checkpoints.

Base44 + Antigravity

Base44 is an optional interface layer if integration is viable. Antigravity supports development; it is not a runtime agent.

Participation by design

Parents, students, teachers, and advisers remain visible participants. Narrow tools expose approved synthetic data, and the eventual application receives the required ArgosX security scan.
